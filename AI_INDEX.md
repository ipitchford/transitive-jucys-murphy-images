Machine-oriented map of claims, evidence and limits. Human readers should start with [README.md](README.md) ("What

## Normalisation

S_n = symmetric group on [n]; R = commutative ring with identity; Z(R S_n) = centre of the group algebra.
K_λ = class sum of cycle type λ ⊢ n. z_λ = prod_i i^{m_i} m_i!; h_λ = gcd{ i m_i : m_i > 0 }. Jucys–Murphy elements
J_1 = 0, J_i = (1 i) + ... + (i−1 i). Λ_R = symmetric functions over R; E_n(f) = f(J_1, ..., J_n, 0, ...) (ordinary
evaluation). Word = sequence of transpositions; orbit partition Orb(w) = components of the graph of its transpositions;
transitive = Orb(w) is the one-block partition. T_n(f) = transitive image (Definition 2.2): keep only transitive words
in the expansion of f(J). Set partitions Π_n ordered by refinement; μ(π) = (−1)^{k−1}(k−1)! for k blocks. J^π_i =
Jucys–Murphy elements of the Young subgroup S_π; H_π = sum of S_π; G_α = sum of H_π over π of type α.
L_n = { sum c_λ K_λ : z_λ/h_λ divides c_λ for every λ }. CLR = Campion Loth and Rattan, doi:10.1112/blms.70170
(arXiv:2403.08354); GJ = Goulden and Jackson, doi:10.1016/j.jalgebra.2009.01.004; Féray = doi:10.1016/j.ejc.2011.09.035;
Jucys 1974 = doi:10.1016/0034-4877(74)90019-6; Murphy 1983 = doi:10.1016/0021-8693(83)90219-3; Murray 2004 =
doi:10.1016/j.jalgebra.2003.02.007. Theorem numbering follows the manuscript (one shared counter per section).

## Limits

The integral image is determined only for n ≤ 7 (an attempt at n = 8 was not completed and nothing is claimed for it).
The n = 6 parity condition has no conceptual explanation. Closed forms for transitive images of classical bases (CLR
Question 13) are not addressed. The proofs of Sections 2–6 do not depend on the computer checks, except Theorem 6.3.
